WorthIt Guides Parser

Build WoW guide pages and generate core.Guides Lua without hand-writing widgets. Works offline.

Guide details

Move widgets with ↑ ↓, edit their fields, then generate Lua. Icons use WoW texture paths such as Interface\Icons\Ability_Mount_RidingHorse.

Lua output

This generates a guide page, not the core.lua navigation entry. The category and guide names must match your existing navigation. Zone is a numeric WoW UI map ID. The preview is approximate, not an in-game renderer.
