Save your work

2. In-game preview

Approximate preview; WoW renders its own text, item links and waypoint buttons.

3. Export to WorthIt Guides

In WoW, open WorthIt Guides → My Guides, paste the full package into Import Category Package, and click Import Package. This tool exports the existing WITGUIDES_EXPORT_V1 format.
